🔁 Proxy Feeds — Using corsproxy.io
Why a proxy? These source websites block direct browser requests for their own security reasons (called CORS restrictions). To get around this, your browser sends the request through corsproxy.io — a free public middleman service. The path is: Your Browser → corsproxy.io → Source Website → back to your browser. corsproxy.io does not store or log your content.

⚙️ How to Change or Remove the Proxy
The proxy setting is one line in this file. Search for const CORS_PROXY in the script section at the bottom of this HTML file. Change that one value to switch proxies or remove the dependency entirely.
1️⃣ Option 1 — Switch to a different free proxy
Find const CORS_PROXY = 'https://corsproxy.io/?' in the script and replace the URL with one of these alternatives:
https://api.allorigins.win/raw?url=
https://corsproxy.io/?
https://proxy.cors.sh/
2️⃣ Option 2 — Remove proxy dependency entirely (recommended long-term)
The cleanest long-term solution is to set up Power Automate to fetch these RSS feeds server-side (once IT enables the RSS connector) and write the results into a SharePoint list. This dashboard would then read from SharePoint instead of directly from RSS feeds — no proxy needed, no CORS issues, and it runs 24/7 even when this page is closed. This is the recommended path once Power Automate access is fully enabled.
3️⃣ Option 3 — Self-host your own proxy inside Rocket's network
If IT can deploy a small internal server (Node.js or Python, takes about 30 minutes to set up), it can act as your own CORS proxy entirely within Rocket's network. No external dependency at all. Ask IT about deploying a lightweight CORS proxy on an internal server — the code is open source and takes minimal resources.
